# BryteBox-Configs (Windows 7)
This is intended to be a direct library for Windows 7 specifically, and is also a work in progress. Also if any mod creator wants their stuff removed, just dm me.
<br>
I am expecting that you use Windows 10, but a lot of this stuff SHOULD work on 11. If youve never modded Windows before, please try all of this in a virtual machine first. Learn how this all works first before making mistakes to your main computer.
